# BOITUMELO B PRODUCTIONS

> **"Stories Worth Feeling."**  
> *Films that move people. Visuals that move brands.*

A cinematic, high-end digital flagship experience prototype for **BOITUMELO B PRODUCTIONS**, an Australian-focused creative film and video production house specializing in documentary cinema, visionary music videos, corporate narratives, and commercial films.

---

## 📽️ Experience Overview

This project is a complete, multi-page frontend prototype built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**. It incorporates an editorial film journal cadence, responsive layouts, accessible video playback controls, and a dedicated production management CMS prototype.

### Core Disciplines
1. **Documentary & Film Production:** Authentic non-fiction storytelling, human-centred narratives, and 2.39:1 anamorphic cinema.
2. **Music Video Production:** Rhythmic, visually expressive artist collaborations, dynamic lighting sync, and high-energy motion.
3. **Corporate Video Production:** High-trust corporate communications, executive thought leadership, and investor pitch cinema.
4. **Brand & Commercial Films:** High-craft commercial cinema, sensory product aesthetics, and national campaign releases.

## 🗺️ Route Directory

- **`/`** — Full-Screen Cinematic Video Hero, Selected Work Showcase, Disciplines Breakdown, Methodology, and Testimonials.
- **`/about`** — Studio Story, Creative Philosophy, Cultural Protocols, and On-Location Archival Gallery.
- **`/services`** — Comprehensive directory of all four production disciplines, scope deliverables, and commercial FAQs.
- **`/services/documentary-film`** — Dedicated Documentary & Non-Fiction Film page.
- **`/services/music-videos`** — Dedicated Music Video Production page.
- **`/services/corporate-video`** — Dedicated Corporate Video page.
- **`/services/brand-commercials`** — Dedicated Brand & Commercial Cinema page.
- **`/work`** — Interactive portfolio archive with client-side category filtering and hover video previews.
- **`/work/[slug]`** — Dynamic case studies featuring full cinema video player, metadata matrix, narrative challenge, technical notes, and BTS gallery.
- **`/testimonials`** — Authentic client reflections, editorial quote blocks, and collaborator credits.
- **`/contact`** — Direct studio dialogue, validated contact form, Australian service footprint, and WhatsApp integration.
- **`/book`** — 5-step collaborative creative brief wizard with provisional calendar slot picker.
- **`/admin`** — Production Management CMS Prototype (Overview metrics, Projects CRUD, Enquiries inbox drawer, Media library, Site settings).

## 🚀 Getting Started

### Prerequisites
- Node.js `v18.17+` or `v20.x` / `v22.x`
- npm `v9+` or `v10+`

### Installation
```bash
# Clone the repository
git clone https://github.com/luxestudio-live/BOITUMELO-B-PRODUCTIONS.git

# Enter project directory
cd BOITUMELO-B-PRODUCTIONS

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the public website, or [http://localhost:3000/admin](http://localhost:3000/admin) to preview the CMS.

### Build & Production
```bash
npm run build
npm run start
```

## 🔒 Prototype Scope Note
This is a **Frontend-Only Prototype**. Form submissions, brief creation, and CMS interactions are simulated locally on the client without writing to live backend databases or remote APIs.
